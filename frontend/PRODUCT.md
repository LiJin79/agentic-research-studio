# Knowledge Studio

A Vue workspace for evidence-backed chat, uploaded knowledge, research tools and editable reports.
The user is learning the engineering stack while making the application useful for real research.

Backend: FastAPI, LangGraph, PostgreSQL, Redis, Qdrant and configured model APIs.
Preserve working conversation and upload flows, permission checks, model selection and report export.
Do not add marketing pages, invented metrics or pretend provider availability.
Optional tools require server-side credentials; public tools can fail because of network limits.
The audience needs readable Chinese, source inspection and predictable desktop/mobile controls.
