# 全界面字号与字体调整

本次保留 A 功能配色，不仅调整对话正文，也提高导航、会话列表、搜索、来源、工具和设置的字号。

## 字体角色

- 品牌与界面标题：本地托管的 LXGW WenKai 700，中文文楷字体。
- 导航、输入、会话列表与正文：Noto Sans SC Variable，保持清晰与稳定。
- 代码与技术标识：Consolas / 系统等宽后备。

两种中文字体都由项目自身提供，不需要浏览器访问外部字体网站。
授权副本保存于 frontend/public/fonts，标题字体只加载实际使用的粗体字重。

## 字号角色

默认字号偏好 18px，减号、加号、重置同时影响正文与界面。

| 区域 | 默认字号 |
| --- | --- |
| 主导航与新会话 | 18px |
| 会话列表、搜索、设置与主按钮 | 17px |
| 分组、状态、技术标识 | 15px，最小 14px |
| 品牌与详情标题 | 24px |
| 对话正文 | 桌面 18px，手机 17px |

字号仍保持 16-22px 的偏好边界；不是浏览器缩放，也不会强制覆盖用户的浏览器设置。
侧栏和按钮同步增加空间，手机头部分两行，避免大字号挤压会话标题。

## 验证

前端 9 项测试通过。桌面、宽屏、平板、390px 手机和 320px 手机布局检查通过，
包括最大字号侧栏、模型选择、导出弹窗及键盘焦点。截图见 evaluation/workspace-typography。

## 是否需要组件库

字体、字号、字重、行距与颜色属于设计样式，不必引入新组件库。
项目当前使用 Vue 组件、Lucide 图标、Markdown 渲染和字体包。
若后续增加复杂数据表、日期选择、日历或树形目录，可评估 PrimeVue；
本次不为字体修改引入整套组件或替换已经工作的交互。
