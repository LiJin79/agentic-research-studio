# 项目功能验收与残留问题检查

日期：2026 年 10 月 12 日。对象为本机 Docker 部署的知研工作台。

## 结论

本次发现并修复了联网意图误判、会话记忆被校验删除、PPT 虚假引用缺少检查及断连提示不清晰的问题。修复已部署，下面列出的功能检查通过。结论只适用于这些场景，不表示不存在任何其他缺陷，也不代表生产压测或安全审计完成。

## 发现和修复

| 问题 | 实际表现与原因 | 修复及关键代码 |
| --- | --- | --- |
| 否定句和概念解释误触发搜索 | “不需要联网搜索”“解释网页搜索是什么”仅因含关键词被当成工具执行请求 | `search_policy.py` 的 `requires_web_search()`、`web_search_denied()`；前端 `workspace.js` 的对应判断；本轮明确拒绝优先于开关偏好 |
| 对话记忆被校验节点删除 | 真实验收中，回答节点正确回忆代号，但 verifier 没收到历史，判定无依据；修订再次缺历史，改成用户没提供代号 | `prompts.py` 的 `VERIFY_PROMPT`、`REVISE_PROMPT` 与 `workflow.py` 的 `verifier()`、`revise_answer()` 都传入历史；已通过真实代号回忆与单元回归 |
| PPT 结构合法但引用可能无效 | 大纲字段校验不能阻止模型新造 `[W99]` 等编号 | `ArtifactService.create()` 将大纲引用与真实来源集合比对，无效引用不能生成文件；异常场景使用测试模型验证 |
| 断连只有 Failed to fetch | 浏览器无法连接服务时只显示底层英文错误，容易被误认作密钥问题 | `frontend/src/api.js` 的 `request()` 提供中文连接排查提示；用户取消仍保持 AbortError，避免误判为网络故障 |
| 验收脚本不读取本机访问口令 | 两个旧脚本只读终端变量，口令仅填 .env 时可能导致验收 401 | `verify_project.py`、`check_deployment.py` 改为读取项目 Settings；当前部署使用实际配置验收 |

## 未验证和现有边界

- Ollama GPU 推理、Tavily 替代供应商没有本次实际验收，不能标记为已通过。
- 没有进行高并发压测、长时间稳定性测试、网络/断电故障演练或正式安全审计；未停止 Docker 来测试断连。
- 当前是单个私有工作空间，不包含多租户 RBAC、公网 TLS 和完整身份系统；默认只绑定本机。
- 模型输入历史限制为最近 30 条及 12000 字符，并不提供无限长期记忆或历史摘要。此次记忆验收是短会话。
- 模型和搜索配置仍采用一个全局供应商，没有实现多密钥池或自动供应商故障转移。
- Word/PPT 是回答转办公文件的技能，不是操作桌面 Office、任意模板复刻或自动搜图。模型提炼内容和“证据检查通过”仍需要人工核对。
- 测试依赖有一条 Starlette/AnyIO 弃用警告，不影响本次结果；后续升级依赖时需要回归。
