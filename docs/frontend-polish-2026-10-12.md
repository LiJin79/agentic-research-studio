# 前端美化与验证记录

## 设计方向

结合 Taste Skill 的保留品牌改版原则，以及 Impeccable 的操作型界面规范，保留 Vue、Lucide 图标、绿色品牌和原有功能。重点改善阅读、信息层级和任务操作，不增加营销落地页、外部字体请求或装饰动画。

## 修改位置

| 文件 | 主要调整 |
| --- | --- |
| `frontend/src/styles.css` | 将原有叠加样式整理为统一变量与样式；优化侧栏、聊天、输入框、资料面板、知识库和弹窗；加入手机文档行布局和减少动态效果支持 |
| `frontend/src/App.vue` | 保留原有请求与业务逻辑；新增弹窗焦点管理 `watch(modal)` 和键盘处理 `handleDialogKeydown()`；增加当前导航状态、连接状态文字及资料侧栏遮罩 |
| `scripts/ui-design-check.cjs` | 使用 Playwright 和浏览器拦截数据，验证布局、字体、导航、大字模式、来源面板和 Word/PPT 弹窗，不写入数据库、不调用云端模型 |

正文默认桌面 18px、手机 17px；大字模式分别为 20px 和 19px。资料与控件采用独立字号，不随视口宽度缩放。

## 验证结果

- 生产构建通过，Docker 前端镜像构建通过。
- 原有 8 项前端测试通过，包括 SSE 分帧、断连提示、搜索意图和校验标签。
- Edge 无窗口浏览器验证 1440×1000、390×844、1024×900、1920×1080 四种视口。
- 四种视口均无浏览器脚本异常、页面横向溢出或检查范围内的按钮碰撞。
- 大字模式、知识库导航、资料执行记录、Word/PPT 生成入口与联网许可确认通过。
- 弹窗输入框自动聚焦、Tab/Shift+Tab 循环、Escape 关闭及关闭后焦点返回通过。
- 已只重建前端容器；8080 页面实际加载新的品牌变量和 18px 阅读字号。
- 主要控件、次要标签、输入框和页脚文字的实测对比度均高于 4.5:1；此检查不等同完整无障碍审计。
- 通过前端 Nginx 调用就绪接口，PostgreSQL、Redis、Qdrant 均返回正常。

独立截图和结构化结果保存在 `evaluation/design-refresh/`。其中改版效果截图使用明确标识的布局测试数据，不应视作真实模型回答。改版前截图读取原有部署。未覆盖之前的功能验收报告。

## 使用与边界

常用入口仍为 http://localhost:8080/ 。浏览器保留旧页面时，用 Ctrl+F5 强制刷新。

本次没有修改 `.env`、后端业务、模型调用、数据库内容或知识库内容。办公功能验证覆盖入口、弹窗和键盘交互，没有重新消耗模型额度生成 PPT 或执行网页搜索；真实云端功能的既有验收见 `function-audit-2026-10-12.md`。
