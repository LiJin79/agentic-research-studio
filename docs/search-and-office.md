# 网页检索与办公文档技能

## 本次修复

- 明确要求网页搜索时，以当前提问为准，不被旧知识库问题覆盖。未授权联网会明确阻止，前端提供开启并发送的确认。
- 联网开关和大字阅读偏好在浏览器本地保存。密钥只保留在后端。
- `site:域名` 和明确的域名限定会传给搜索服务，并二次核对返回 URL 的真实主机名。第三方网页不会被当作官方资料。
- 供应商请求失败与搜索零结果分开处理。没有执行工具就不能声称完成搜索，没有可用证据就不能标成证据检查通过。
- 工具调用名称、搜索词、结果数量、域名约束持久化到助手消息，刷新会话仍可查看。
- 检索提示词现在包含真实 URL；前端区分一般回答、模型检查、证据检查和证据不足，不宣称事实认证。

## Word 和 PPT

每条完成的助手回答下方有 Word 和 PPT 图标，选择后输入标题即可下载。

- Word：已有回答直接排版，保留标题、段落、列表、表格和文末资料来源，不额外调用模型。
- PPT：调用当前生成模型，将已有回答提炼成受约束的 JSON 大纲，再生成可编辑幻灯片、演讲者备注和资料来源页。会产生模型调用费用。
- 可以先要求助手撰写报告或汇报内容，完成后生成相应文件。当前能力不是任意模板复刻，也不自动联网找图片、操作桌面 Office 或读取个人网盘。
- 只有已完成的助手消息可以导出。后端从数据库读取消息，不接受客户端任意文件路径。生成文件直接下载，不在服务器累积临时文件。
- PPT 正文长度、页数和要点长度都有上限；格式错误明确返回失败，不生成假的文件路径。
- 生成文档不能提升原资料的可信度。未通过检查的回答会在文档中保留核对提示，仍需人工审核。

| `frontend/src/workspace.js` | 联网许可判断与准确的检查标签 |
| `frontend/src/App.vue` | 联网确认、大字阅读、办公文档入口 |

## 使用方式

普通概念可以直接回答；内部资料走知识库。需要实时网页时开启联网，或在明确提出搜索后接受许可确认。
指定官方来源可以写 `site:fastapi.tiangolo.com`，系统会把域名条件传给搜索服务。严格限定下无结果不会偷偷放宽范围。
聊天历史只用于理解上下文，网页研究工具以当前问题为任务，避免上一轮编号和内容污染本轮检索。

修改代码后需要重新构建部署；只填写密钥时只需重新创建 API 和 worker。
